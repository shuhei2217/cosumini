# アクセス数の見かた・設定手順

サイトのアクセス数（見られた回数）を、外部サービスの登録なしで計測できるようにしました。
データはすべて自分のサーバー内に保存されます。

## 1. 使い始める手順（FTP作業は不要）

1. このブランチを `main` にマージする（自動デプロイでサーバーに反映されます）
2. ブラウザで `https://（サイトのURL）/stats.php` を開く
3. 最初の1回だけ、画面上でパスワードを決める
4. 完了。以後はそのパスワードでアクセス数を見られます

> **公開後はお早めに手順2〜3を済ませてください。**
> パスワード未設定の間は、URLを知っている人なら誰でも先に設定できてしまいます。
> （見られるのはアクセス数だけで、お客様の個人情報は含まれません）

一度ログインすると30日間はパスワード入力なしで開けます。
スマホのホーム画面に追加しておくと便利です。

## 2. パスワードの決め方（3通り・どれか1つでOK）

優先される順に記載しています。

| 方法 | やり方 | 備考 |
|---|---|---|
| **① 画面上で設定**（おすすめ） | `stats.php` に初回アクセスして決める | FTP不要。`data/stats-auth.php` にハッシュ化して保存されます |
| ② GitHub の Secrets | リポジトリの Settings → Secrets and variables → Actions → New repository secret で `STATS_PASS` を登録 | 次回のデプロイで自動反映。FTP不要 |
| ③ `config.php` に直接書く | サーバー上の `config.php` に `'stats_pass' => '…',` を追加 | FTPまたはサーバーのファイルマネージャーが必要。これが最優先されます |

※ 訪問者の重複判定に使う内部ソルトは**自動生成**されるため、設定は不要です。

### パスワードを忘れたとき

サーバー上の `data/stats-auth.php` を削除すると、次回アクセス時に再設定できます。
（②で設定した場合は、GitHub の Secret `STATS_PASS` を書き換えて再デプロイしてください）

## 3. アクセス解析ページで見られる内容

- 今日 / 昨日 / 直近7日 / 今月 / 累計 のアクセス数と訪問者数
- 直近30日の推移グラフ
- 今日の時間帯別アクセス（何時に見られているか）
- 流入元（Google・Instagram など、どこから来たか）
- よく見られたページ
- スマホ比率
- 日別データの CSV ダウンロード（Excelで開けます）

## 4. 仕組み（ファイルの役割）

| ファイル | 役割 |
|---|---|
| `count.php` | アクセスを記録する受け口。index.html の末尾スクリプトから呼ばれます |
| `stats.php` | 集計を見るページ（パスワード保護） |
| `data/access.json` | 集計データの保存先。サーバー上で自動生成されます |
| `data/salt.txt` | 内部ソルト。サーバー上で自動生成されます |
| `data/stats-auth.php` | 解析ページのパスワード（ハッシュ化して保存） |
| `data/.htaccess` | 上記データを外部から直接ダウンロードできないようにする設定 |

- `data/` の中身は GitHub に保存されず、自動デプロイでも消えたり上書きされたりしません。
- 検索エンジンのロボット（Googlebot 等）のアクセスは数えません。
- 同じ人が10秒以内に同じページを開き直した場合は二重に数えません。
- `/index.html` と `/` は同じページとして集計します。
- 保存しているのはアクセス数だけです。氏名・IPアドレスなどの個人情報は保存しません
  （同じ訪問者かどうかの判定用に、IPをハッシュ化した値を最大7日間だけ保持します）。

## 5. Google アナリティクス（GA4）も使いたい場合

`index.html` の `<head>` 内に、コメントアウトされた GA4 用のタグを入れてあります。
`G-XXXXXXXXXX` を自分の測定ID（ https://analytics.google.com/ で無料取得）に書き換え、
前後のコメント記号（`<!--` と `-->`）を外すと有効になります。

自前カウンター（stats.php）だけでも十分使えるので、そのままでも問題ありません。

## 6. データを初期化したいとき

サーバー上の `data/access.json` を FTP で削除すると、次のアクセスからゼロで数え直します。
（パスワードの設定 `data/stats-auth.php` は別ファイルなので消えません）

## 7. 何が「アクセス数」に数えられるか

数えるのは**サイトのページを実際に見た訪問**だけです。次のものは数えません。

- アクセス解析ページ（`stats.php`）を開いたとき
- 検索エンジンのロボット（Googlebot 等）のアクセス
- 同じ人が10秒以内に同じページを開き直したとき

数えなかったものも「サーバーに届いた直近の記録」には理由付きで残るので、
動作確認には使えますが、お店の数字は汚れません。

## 補足：なぜ config.php は GitHub に置けないのか

`config.php` には LINE のチャネルアクセストークン（他人に知られると、なりすまして
通知を送られてしまう秘密の鍵）が入っています。GitHub に置くと漏洩の恐れがあるため、
意図的に `.gitignore` と自動デプロイの両方から除外しています。
そのため、アクセス解析のパスワードも `config.php` を触らずに設定できるようにしてあります。
